# 나조토키 도우미 (謎解き 도우미)

일본어 謎解き(나조토키) 문제를 풀 때 막히지 않도록 도와주는 도구 모음입니다.
인터넷 없이도 동작하는 정적 HTML 한 장(`index.html`)으로 빌드되며, 상단 토글로 **여섯 가지 도구**를 오갑니다.
소스는 `src/` 아래 기능별 TypeScript 모듈이고, `pnpm build` 가 그것을 루트 `index.html` 한 파일로 묶습니다(아래 「개발」 참고).

| 도구 | 하는 일 |
| --- | --- |
| **도도부현** | 47 도도부현을 검색·일람·지도·실루엣으로 탐색 |
| **현청소재지** | 위와 같되 기준을 현청소재지(시 이름)로 전환 |
| **규칙 그래프** | 여러 단어의 빈칸을 「같은 글자·다음 글자」 같은 규칙선으로 잇고 제약을 전파·검증 |
| **바바누키** | 여러 단어의 겹치는 글자를 지우고 남는 글자를 읽는 퍼즐 도우미 |
| **시리토리** | 여러 단어로 만들 수 있는 끝말잇기(しりとり)를 방향 그래프로 그리고 가장 긴 체인을 강조 |
| **폴리오미노** | 도면(구멍·글자)을 정하고 피스를 골라 끌어다 맞추는 폴리오미노 퍼즐 풀이 + 답 전수 탐색 |

> **바바누키·시리토리는 영어 단어도 입력 가능**합니다(영어는 대소문자 무시). 일본어가 기본이지만 영어로 출제되는 나조토키에도 그대로 쓸 수 있습니다.

## 실행

브라우저로 루트의 `index.html`을 그냥 열면 됩니다(더블클릭 또는 `file://`). 빌드 산출물이 저장소에 같이 들어 있으므로 Node 없이도 바로 쓸 수 있습니다.
로컬 서버로 띄우려면:

```bash
python3 -m http.server 8917
# → http://localhost:8917
```

선택한 도구·옵션·입력 내용은 **새로고침 후에도 유지**됩니다(localStorage).

## 개발

패키지 매니저는 **pnpm** 을 씁니다(`package.json` 의 `packageManager` 에 버전 고정). Node 20 이상에서 `corepack enable` 한 번이면 맞는 pnpm 이 자동으로 쓰입니다.

```bash
corepack enable    # 최초 1회 (pnpm 이 없을 때)
pnpm install
pnpm dev           # Vite 개발 서버 (src/ 를 바로 띄움, 수정 즉시 반영) → http://localhost:8917
pnpm check         # 타입체크 + 단위 테스트 + 빌드 (커밋 전에 한 번)
pnpm build         # src/ → 루트 index.html 한 파일로 번들 (CSS·JS·지도 SVG 인라인)
pnpm test          # vitest — 순수 함수 단위 테스트
```

> **루트 `index.html` 은 생성 파일입니다.** 직접 고치지 말고 `src/` 를 고친 뒤 `pnpm build` 로 다시 만들어 함께 커밋하세요.

## 1. 도도부현 / 현청소재지 검색

상단 토글로 **도도부현 ↔ 현청소재지** 모드를 바꾸면 아래 네 탭이 그 기준으로 동작합니다.

### 🔎 검색
- **와일드카드**: `*` = 임의 글자(0개 이상), `?` = 정확히 1글자. 와일드카드가 없으면 부분일치.
  - 예: `??` 두 글자 / `*やま` ~やま로 끝 / `か*き` か로 시작 き로 끝 / `山*` 山으로 시작하는 한자
  - 전각 `＊` / `？`도 반각 `*` / `?`와 동일하게 처리됩니다.
- **검색 대상**: 전체 / 읽기(かな) / 한자 / 로마자 / **짝 이름** (가타카나 입력도 히라가나로 정규화)
  - **짝 이름**: 현청소재지 모드에서는 **소속 도도부현 이름**으로, 도도부현 모드에서는 **현청소재지 이름**으로 찾습니다(かな·한자·로마자·와일드카드 모두 가능). 예: 현청소재지 모드에서 `ほっかいどう` → 札幌市, `山*` → 山形市·山口市·甲府市(山梨). 「현청 ↔ 도도부현 변환」 문제용.
- **글자수(かな) 필터** + **정렬**: 사전순(50음, 기본) / 글자수순 / JIS순(후생노동성)
- **기본은 간단히, 「자세히 보기」로 전체**: 결과 카드는 기본적으로 한자+요미가나만 보여 한눈에 훑기 쉽고, 「자세히 보기」를 켜면 지역·글자수·로마자·현청 등 상세 정보가 펼쳐집니다.
- **「요미가나 크게」**: 한자보다 가나를 먼저 보는 경우를 위해, 카드·실루엣 타일에서 한자와 요미가나의 위치를 맞바꿔 요미가나를 크게 표시합니다(검색·전체 보기·모양 탭 공통).
- **현청소재지 모드의 소속 도도부현**: 현청소재지 모드에서는 간단 보기 카드에서도 작은 글자 줄(요미가나, 「요미가나 크게」면 한자) 옆에 `北海道` 같은 **칩**으로 어느 도도부현의 현청인지 표시됩니다(현청≠현명이면 테두리를 강조). 모양 타일에도 같은 칩이 붙습니다.
- **가리기**: 카드·지도·실루엣 어디서든 클릭하면 회색으로 흐려져 후보에서 제외됩니다. 이 상태는 **모든 탭과 새로고침 후에도 유지**되고(localStorage) 모든 뷰에 함께 반영됩니다. 가린 항목이 있을 때만 헤더에 「되돌리기」가 나타납니다.

### 📋 전체 보기
47개 전부를 **글자수 그룹 / 사전순 / JIS순 / 지역별**로 묶어서 봅니다.

### 🗾 전체 지도
일본 전도에 이름을 매핑. 호버하면 상세(읽기·로마자·지역·현청)가 뜨고, **클릭하면 다른 탭과 똑같이 회색으로 가려집니다**(가린 상태는 모든 탭에 반영·저장). 가린 땅의 이름 라벨은 취소선으로 표시됩니다.
「이름 표시」 끄면 퀴즈처럼 쓸 수 있고, 「지역별 색」으로 8지방 색을 입힐 수 있습니다.

### 🟩 모양 → 이름
초록색 땅덩이 실루엣 47개를 이름(한자+かな)과 함께 봅니다 — 「이 모양이 어느 현?」 대조용. 모양을 클릭하면 회색으로 가려지고 모든 탭에 반영됩니다. 정렬·그룹은 **전체 보기와 동일**(글자수 그룹 / 사전순(50음) / JIS순(후생노동성) / 지역별).
실루엣은 본섬(가장 큰 땅덩이) 기준으로 맞춰, 멀리 흩어진 작은 섬(鹿児島의 奄美 군도, 沖縄의 외곽 섬 등) 때문에 본섬이 작아지지 않도록 했습니다.

## 2. 규칙 그래프

「○글자 단어인데 둘째 글자가 같다 / 다음 글자다」처럼 **글자 사이의 관계가 힌트로 주어지는** 나조토키를 풀기 위한 도구입니다. 빈칸 단어들을 만들고, 칸과 칸을 규칙선으로 이어 제약을 시각화·전파·검증합니다.

### 만들기
단어를 두 가지 방법으로 추가합니다.
- **단어 입력**: 단어를 적고 **「+ 단어 추가」**(또는 엔터)하면 글자가 채워진 단어가 바로 만들어집니다(가타카나는 히라가나로 정규화, 1~12글자).
- **글자 수만**: 글자를 아직 모르면 **「또는 글자 수(1~12)」 → 「+ 빈 칸」** 으로 빈칸 줄만 늘립니다.

단어는 드래그 가능한 **캔버스**와 오른쪽 **단어 목록**(밑줄 빈칸)에 동시에 나타납니다. 칸/슬롯을 클릭하면 떠오르는 입력창에서 글자를 한 글자씩 채우거나 고칠 수 있습니다.

### 단어 입력 모드 (단어 전체를 한 번에)
단어 목록의 각 단어에 있는 **「✎ 단어 입력」** 을 누르면 그 단어 전체를 보통 문장 치듯 한 번에 입력할 수 있습니다(촉음 `っ`·요음 `ゃ` 처럼 모바일 IME에서 한 글자씩 넣기 어려운 글자용).
- **엔터 또는 「저장」** 으로 반영, **Esc 또는 「취소」** 로 되돌립니다. 가타카나는 히라가나로 정규화됩니다.
- `＿` `?` `○` 는 **빈 칸**(그 칸을 비움)으로 해석됩니다. 예: `さ＿ら` → 1·3번째 칸만 채우고 2번째는 비움.
- 입력 글자가 칸 수보다 **많으면 칸이 늘어나고**, **적으면 뒤 칸은 비워집니다**(칸·규칙선은 유지). 칸 타입(小/濁/半)도 유지되며 글자는 그 형태로 변환됩니다.
- 입력창에는 사용자가 넣은 글자만 미리 채워집니다(추론된 글자는 저장 시 사용자 입력으로 굳지 않도록 제외).

한 글자 입력창도 IME 조합 중(`tt`→`っ`, `lya`→`ゃ`)에 값을 덮어쓰지 않도록 고쳐, 조합이 끊겨 `t`·`あ` 같은 조각만 남던 문제를 줄였습니다.

### 규칙선 잇기
**「🔗 규칙 연결」** 을 켜고 한 칸에서 다른 칸으로 드래그하면 규칙 종류를 고를 수 있습니다. 색상 범례는 패널 상단에 표시됩니다.

| 규칙 | 의미 | 선 |
| --- | --- | --- |
| 같은 글자 | 두 칸의 글자가 같음 | 파란 실선 |
| 같은 글자 (탁점 떼기) | 탁점·반탁점을 떼면 같은 글자 (が↔か, ぱ↔は) | 청록 점선 |
| 모음 같음 | あ단/い단… 모음이 같음 | 초록 실선 |
| 자음 같음 | か행/さ행… 자음이 같음 | 보라 실선 |
| 오십음도 다음 | 오십음도에서 N칸 뒤 글자(あ→い→…) | 주황 화살표 |
| 이로하 다음 | 이로하(いろは) 순서에서 N칸 뒤 글자 | 청록 화살표 |

규칙선을 클릭하면 삭제할 수 있고, 채워 넣은 글자가 규칙과 어긋나면 **빨간 점선(규칙 위반)** 으로 경고합니다.

### 칸 제약 · 전역 옵션
- **칸 타입**(칸 우클릭 또는 길게 누르기): 일반 / **작은 글자만(小)** / **탁점만(濁)** / **반탁점만(半)**. 해당 칸엔 그 형태만 들어가도록 제한하고, 입력값도 자동 변환합니다.
- **「작은⇄큰 같은 글자」**: 켜면 `같은 글자` 규칙에서 작은 글자(ぁゃっ)와 큰 글자(あやつ)를 같은 글자로 취급합니다.
- **「탁음 다음」**: 탁음(が·ざ·だ·ば·ぱ행)에서 `다음 글자`를 어떻게 셀지. 누를 때마다 **행 안에서만**(기본, `ご`의 다음 없음) → **が→ざ→だ→ば 이어서**(`ご`→`ざ`, `ぞ`→`だ`, `ど`→`ば`) → **ぱ행까지 이어서**(`ぼ`→`ぱ`) 순으로 바뀝니다. 탁음표를 또 하나의 오십음도처럼 다루는 출제용이며, 청음표(あ~ん)와는 어느 모드에서도 섞이지 않습니다. 「순환」과 함께 켜면 마지막 행 끝(`ぼ`/`ぽ`)에서 `が`로 돌아옵니다. 규칙선 팝업·범례의 「오십음도 다음」에 현재 모드가 표시됩니다.
- 규칙·글자를 채우면 다른 칸으로 제약이 **전파(추론)** 되며, 추론된 글자는 흐린 기울임으로 표시됩니다.
- 단어 목록의 **「삭제」** 는 그 단어에 **입력한 글자나 연결된 규칙선이 있으면** 한 번 확인을 묻습니다(빈 단어는 바로 삭제). 다른 단어의 칸 타입은 그대로 유지됩니다.
- **「전체 삭제」** 로 모든 단어·규칙을 비웁니다.

## 3. 바바누키 (ババ抜き)

여러 단어를 늘어놓고 **겹치는 글자를 지운 뒤 남는 글자를 읽으면 답이 되는** 나조토키(통칭 ババ抜き)를 위한 도우미입니다.

- **단어 입력**: 입력창에 단어를 적고 **엔터** 또는 **「＋ 추가」**. 띄어쓰기·줄바꿈·쉼표(반각 `,` · 일본어 `、` · 전각 `，` · 반각 일본어 `､`)로 구분하면 여러 단어를 한 번에 추가합니다. (IME가 어떤 쉼표를 내든 단어가 나뉩니다.)
- **남은 글자**: 추가된 모든 단어의 글자를 한 풀로 모아 겹치는 글자를 지우고, 남는 글자를 **읽기 순서대로** 크게 보여줍니다.
- **단어별 표시**: 각 단어를 글자 타일로 펼쳐, 지워진 글자는 취소선(회색), 남는 글자는 노란색으로 강조합니다. 단어 옆 **×** 로 그 단어만 지우거나, **「목록 비우기」** 로 전체를 비웁니다.

### 겹침 규칙 (옵션)
| 규칙 | 동작 |
| --- | --- |
| **짝만 지우기** (기본) | 카드 게임 ババ抜き처럼 같은 글자를 짝지어 지움 → 개수가 홀수면 1개가 남음 |
| **겹치면 모두 지우기** | 두 번 이상 나온 글자는 전부 지움 → 딱 1번 나온 글자만 남음 |

> 「짝만 지우기」에서 같은 글자가 3개·5개처럼 홀수로 나오면, 가장 먼저 나온 1개를 남깁니다.

### 글자 맞추기 (옵션)
겹침 판정에만 적용되며 화면 표시는 입력 그대로입니다.
- **カ=か (가나 통일)**: 가타카나와 히라가나를 같은 글자로 취급(기본 켬).
- **작은⇄큰 같은 글자**: ぁ=あ, っ=つ … 작은 글자와 큰 글자를 같게.
- **탁점·반탁점 무시**: が=か, ぱ=は … 탁점·반탁점을 떼고 비교.
- **Aa (영문 대소문자 무시)**: `Apple`=`apple` … 영어 단어를 대소문자 구분 없이 비교(기본 켬).

> 이 옵션들로 서로 다른 모양의 글자가 같은 것으로 묶여 1개만 남을 때, 화면에 보이는 글자는 **그 묶음에서 가장 먼저 입력된 형태**입니다(예: 「탁점 무시」로 `が`·`か`가 묶이면 먼저 친 쪽이 그대로 표시). 답은 실제 글자 모양이 아니라 묶인 음으로 읽으세요.

## 4. 시리토리 (しりとり)

여러 단어를 늘어놓고 **앞 단어의 끝글자 = 뒤 단어의 첫글자** 로 이어지는 끝말잇기(しりとり)를 **방향 그래프**로 그려, 어떤 단어 뒤에 무엇이 올 수 있는지와 **가장 긴 시리토리 순서**를 한눈에 보여주는 도우미입니다.

- **단어 입력**: 입력창에 단어를 적고 **엔터** 또는 **「＋ 추가」**. 띄어쓰기·줄바꿈·쉼표(반각 `,` · 일본어 `、` · 전각 `，` · 반각 일본어 `､`)로 구분하면 여러 단어를 한 번에 추가합니다. **가타카나·영어** 모두 가능합니다(영어는 끝글자→첫글자, 대소문자 무시).
- **가장 긴 시리토리**: 입력 단어로 만들 수 있는 가장 긴 체인(각 단어 1회)을 계산해 `りんご → ごりら → らっぱ …` 처럼 잇는 글자와 함께 보여줍니다.
- **경우의 수 넘기기**: 같은 길이의 최장 체인이 여러 가지면 결과 칸 오른쪽에 **◀ 1 / N ▶** 가 나타나 좌우로 넘기며 볼 수 있고, 그래프의 굵은 주황 체인도 함께 바뀝니다. 순환으로 **시작점만 다른 체인**(`A→B→C`와 `B→C→A`, 끝 단어가 첫 단어로 되돌아오는 경우)은 하나로 묶습니다. 경우가 300가지를 넘으면 `300+`로 표시합니다.
- **그래프**: 최장 체인은 위쪽에 **굵은 주황 화살표**로, 그 외에 가능한 이어짐은 **옅은 화살표**로 그립니다. `ん`으로 끝나 더 이을 수 없는 단어는 **빨간 점선(막다른 길)**, 아무 곳과도 이어지지 않는 단어는 **고립**으로 표시합니다.
- **드래그로 자유 배치**: 규칙 그래프처럼 **노드를 끌어** 원하는 대로 옮길 수 있어, 최장 체인 밖의 관계도 직접 풀어 보며 파악할 수 있습니다. 옮긴 위치는 저장되며, **「자동 정렬」** 로 원래 자동 배치로 되돌립니다.
- **순환(원형) 표시**: `A→B→…→A` 처럼 **빙 돌아오는 관계**(강연결요소)는 노드·화살표를 **보라색**으로 표시하고 목록에 「순환」 배지를 붙입니다 — 최장 체인만으로는 안 보이는 고리를 한눈에 알 수 있습니다.
- **단어별 목록**: 각 단어의 첫·끝 글자와 막다른 길/고립/순환 여부를 보여주고, **×** 로 그 단어만 지우거나 **「목록 비우기」** 로 전체를 비웁니다.

### 잇기 규칙 (옵션)
표시는 입력 그대로이고, 이음 판정에만 적용됩니다.

| 규칙 | 동작 | 기본 |
| --- | --- | --- |
| **カ=か (가나 통일)** | 가타카나·히라가나를 같은 글자로 취급 | 켬 |
| **작은⇄큰 같은 글자** | ぁ=あ, ょ=よ … 작은 글자와 큰 글자를 같게 | 끔 |
| **탁점·반탁점 느슨하게** | が↔か, ぱ↔は … 탁점·반탁점을 떼고 이음 | 끔 |
| **장음(ー) 잇기** | `コーヒー`처럼 `ー`로 끝나면 앞 글자(`ひ`)로 이음 | 끔 |
| **ん으로 끝나면 막다른 길** | `ん`으로 끝나는 단어는 뒤를 이을 수 없게 차단·표시 | 켬 |

> 한자 단어는 읽기를 알 수 없으므로 **히라가나/가타카나로 입력**하세요(기존 도구처럼 가타카나는 히라가나로 통일해 비교).

## 5. 폴리오미노

격자 도면을 피스(칸을 이어 붙인 조각)로 빈틈없이 채우는 퍼즐 풀이 도구입니다. 謎百科의 폴리오미노 생성기에서 「풀이」에 필요한 부분(도면 정의 · 피스 선택 · 드래그 배치 · 답 탐색)만 가져왔습니다.

### 도면
- **크기**: 가로 × 세로 1~20. 「채울 칸」 수와 「선택한 피스 합계」를 항상 비교해 안 맞으면 ⚠ 로 표시합니다.
- **도면 편집** 세그먼트: **배치**(기본) / **구멍**(칸을 누르거나 끌어서 사용하지 않는 칸을 칠함) / **글자**(칸을 눌러 한 글자씩, 엔터·→ 로 다음 칸, ↑↓←→ 이동, Esc 닫기).
- 글자는 부가 기능입니다. 기본값은 **피스를 놓아도 글자가 가려지지 않음**(피스를 반투명하게 그려 비침)이고, 「피스로 글자 가리기」를 켜면 덮인 글자는 숨습니다. 글자가 하나라도 있으면 아래 **「글자 읽기」** 패널에 피스별로 덮은 글자(위→아래, 왼→오)와 덮이지 않은 글자가 나옵니다.

### 피스 선택 (오른쪽 패널)
- **1~6칸** 탭에 자유 폴리오미노 전부(1·1·2·5·12·35종)가 카드로 나오고, 펜토미노는 표준 글자 **I U P F X N Y L Z T W V**, 테트로미노는 I O T S L 로 표시합니다. 카드의 **− / ＋** 로 개수를 정하고 **「제한 없음」** 을 켜면 몇 개든 쓸 수 있습니다. 「이 크기 전부 1개씩」 / 「이 크기 0으로」 일괄 버튼이 있습니다.
- **6칸** 탭에는 **「🎲 주사위 전개도만」** 필터가 있습니다. 접으면 정육면체가 되는 11종만 남기고(카드에 🎲 표시), 「이 크기 전부 1개씩」도 보이는 피스에만 적용됩니다. 주사위 전개도 출제용.
- **자작** 탭: 격자(기본 10×10, ＋ 로 20×20까지)를 눌러(끌어서) 모양을 그리고 「이 모양 저장」. 변으로 이어져 있어야 합니다. 저장한 피스는 다른 피스처럼 개수를 정해 쓰고 「삭제」로 지웁니다.
- 전역 옵션 **「회전 허용」「뒤집기 허용」**. 뒤집기를 끄면 거울상이 있는 피스(S/Z, L/J, 펜토미노 F N P Y Z 등)가 **두 장(이름′)** 으로 나뉘어 각각 개수를 정합니다. 켜고 끌 때 개수와 놓인 피스는 자동으로 이어집니다. 회전을 끄면 카탈로그(또는 자작 피스를 그린) 방향 그대로만 씁니다.

### 배치
- **트레이**의 카드를 도면으로 끌어다 놓습니다. 카드의 **↻ ⇄** 로 미리 방향을 바꿀 수 있습니다. 놓인 피스는 **누르면 선택, 끌면 이동, 도면 밖으로 끌면 트레이로** 돌아갑니다.
- 선택한 피스는 도면 아래 도구줄의 **↻ 돌리기 / ⇄ 뒤집기 / 메모 / 트레이로**, 또는 키보드 **R / F / Delete / 화살표(한 칸 이동) / Esc** 로 다룹니다. **메모**(1~4자)는 피스 위에 표시되고 「글자 읽기」에도 함께 나옵니다 — 피스에 글자가 적힌 출제용.
- 겹치거나 구멍·도면 밖에 걸친 피스는 **빨간 점선**으로, 둘 이상이 덮은 칸은 빨갛게 표시하되 놓는 것 자체는 허용합니다(생각 중 임시로 겹쳐 두기). **「겹침 금지」** 를 켜면 그런 자리에는 놓을 수 없습니다.
- 빈칸 0 · 충돌 0 이면 **「완성!」**. **되돌리기/다시 실행**(Ctrl+Z / Ctrl+Y, 버튼) · **「전부 되돌리기」**(놓은 피스만 트레이로) · **「전체 삭제」**(도면·피스·배치 초기화, 되돌리기 가능).

### 답 탐색
- 「답 탐색」을 펼쳐 **「답 찾기」** 를 누르면 선택한 피스로 도면을 채우는 모든 답을 찾아 **「답 1 / N」** 으로 앞뒤로 넘기고 썸네일(60개까지)로 나열합니다. **「이 답을 도면에 적용」** 으로 놓을 수 있습니다(되돌리기 가능).
- **이미 놓인(충돌 없는) 피스는 고정**하고 나머지만 탐색하므로 힌트로도 쓸 수 있습니다. 유한 개수 피스는 전부 써야 하고, 「제한 없음」 피스는 몇 개든 됩니다.
- 상한은 답 500개 · 300만 단계이며 걸리면 「N+」와 「상한에서 중단」으로 표시합니다. 면적이 안 맞거나 어떤 피스로도 덮을 수 없는 칸이 있으면 탐색 없이 이유를 알려줍니다. 도면·피스·옵션이 바뀌면 이전 결과는 지워집니다.

> 폴리오미노 탭의 모든 내용(도면·글자·선택한 피스·자작 피스·배치·메모·옵션)은 저장되어 새로고침 후에도 남습니다.
